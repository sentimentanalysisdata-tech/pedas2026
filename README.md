# Dashboard analitik DNS — PeDaS 2026

Dashboard Streamlit untuk hasil business analytics data DNS babak final PeDaS 2026.
Seluruh tabel adalah ringkasan agregat dari 11.712.623 pesan DNS; tidak ada data mentah, IP resolver, atau nama domain asli.

Jalankan lokal: `pip install -r requirements.txt` lalu `streamlit run streamlit_app.py`.
